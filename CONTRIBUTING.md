# Contributing

Bug reports, focused improvements, and documentation fixes are welcome. Start with [SUPPORT.md](SUPPORT.md) for help or open an issue to discuss substantial changes.

Use Node.js 24 and pnpm 10.27.0:

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm ext:package
```

Use **Run Extension** in VS Code to open an Extension Development Host for manual testing. Check a new profile with the setting unset, explicit true and false preferences, workspace overrides, and the Command Palette controls. Verify that selection copying is performed by VS Code and that no startup notification appears.

The static website lives in `website/`. Shared layout and metadata are generated by `scripts/build-site.mjs`:

```sh
pnpm site:build
pnpm site:check
pnpm site:preview
pnpm site:test
```

Browser tests use locally installed Google Chrome by default. In CI, set `PLAYWRIGHT_CHANNEL=chromium` and install it with `pnpm exec playwright install --with-deps chromium`. Check desktop and mobile layouts, keyboard navigation, copy buttons, and support search. Regenerate the committed 1200 × 630 social image with `node scripts/generate-social.mjs` after editing `website/social-card.html`.

Preserve the native-setting approach, explicit user preferences, accessibility, and the absence of telemetry. Make claims that can be verified from the source. Do not add invented ratings, download counts, or keyword stuffing.

The Pages workflow builds and deploys the website on pushes to `main`. Marketplace and Open VSX releases are separate and happen only when a matching version tag is pushed with publishing credentials configured.
