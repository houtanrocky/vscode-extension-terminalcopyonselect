# Support

Start with the [support page](https://houtanrocky.github.io/vscode-extension-terminalcopyonselect/support/) or the [setup guide](https://houtanrocky.github.io/vscode-extension-terminalcopyonselect/guide/).

If terminal selections do not copy, open VS Code Settings and search for `terminal.integrated.copyOnSelection`. Enable it and review Workspace or Remote overrides. The extension preserves explicit settings, including `false`.

To stop automatic copying, set that setting to `false`. Disabling or uninstalling the extension does not reset the saved setting.

For a reproducible bug, [open a bug report](https://github.com/houtanrocky/vscode-extension-terminalcopyonselect/issues/new?template=bug_report.yml) with your editor version, extension version, operating system, shell, relevant settings, and reproduction steps. Reports are public; remove secrets and private output.

For ideas, [request an improvement](https://github.com/houtanrocky/vscode-extension-terminalcopyonselect/issues/new?template=feature_request.yml). To support the project, star the repository, leave an honest Marketplace review, or contribute a fix or documentation improvement. This is a community project; response times vary.
